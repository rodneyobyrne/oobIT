# oobIT

**oobIT** (pronounced “oob it”) is an oobCREATIVE product exploring a simpler front door for practical AI and business technology decisions.

The first question is not “Which software do you want?” It is: **What are you trying to make easier?**

## Current release
v0.1 is a browser-only interview prototype. It uses explicit decision rules so the interaction can be tested before introducing vendor ranking, affiliate economics, LLM variability or persistent personal data.

## Run locally
```bash
npm run serve
```
Open `http://localhost:4173`.

## Validate
```bash
npm run validate
```
